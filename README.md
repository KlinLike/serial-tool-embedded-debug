# PyQt 串口助手 (PyQt Serial Tool)

这是一个使用 Python 和 PyQt6 开发的简易桌面串口调试助手。它提供了一个简洁的用户界面，用于与串口设备进行通信，支持自动刷新、自定义波特率、数据筛选和保存等功能。

## ✨ 主要功能

### 串口管理
- **自动检测设备**: 实时监测串口设备的插入和拔出
- **自动重连**: 串口断开后自动检测并重新连接
- **手动刷新**: 提供手动刷新按钮，立即更新可用串口列表
- **记忆功能**: 自动记住上次使用的串口和波特率
- **多波特率支持**: 支持 9600 ~ 2,000,000 的多种波特率

### 数据显示与过滤
- **实时数据显示**: 在文本框中实时显示从串口接收到的数据
- **实时过滤器**: 
  - **包含过滤**: 只显示包含特定关键字的数据（支持多关键字，用 `;` 分隔）
  - **排除过滤**: 排除包含特定关键字的数据（支持多关键字，用 `;` 分隔）
- **历史记录筛选**: 对已接收的数据进行二次筛选，快速定位关键信息
- **智能滚动控制**: 
  - 默认自动跟踪最新日志
  - 向上滚动查看历史时自动暂停跟踪
  - 滚动回底部时自动恢复跟踪
  - 可手动切换跟踪状态

### 日志管理
- **自动日志保存**: 
  - 所有数据自动保存到 `serialLog/` 文件夹
  - 日志文件名带时间戳，便于查找
  - 自动清理超过指定天数的旧日志（默认 3 天）
- **手动导出**: 将当前显示的内容导出为 txt 文件
- **清空显示**: 一键清空屏幕显示和缓存数据


## 🛠️ 环境配置

本项目推荐使用 [Anaconda](https://www.anaconda.com/products/distribution) 来管理Python环境和依赖。

### 方法一：使用 Conda 环境（推荐）

1.  **克隆或下载项目**
    ```bash
    git clone <项目地址>
    cd serial-tool-embedded-debug
    ```

2.  **创建 Conda 环境**
    打开 Anaconda Prompt (或终端)，进入项目根目录，执行以下命令创建独立环境：

    ```bash
    conda create --name serial python=3.12 -y
    ```

3.  **激活环境**
    ```bash
    conda activate serial
    ```

4.  **安装依赖库**
    在已激活的环境中，安装所有必需的第三方库：

    ```bash
    pip install pyqt6 pyserial pyinstaller
    ```

### 方法二：使用 requirements.txt

如果项目包含 `requirements.txt` 文件，可以直接安装：

```bash
conda activate serial
pip install -r requirements.txt
```

### 依赖说明

- **PyQt6** (6.7.1+): GUI 框架
- **pyserial** (3.5+): 串口通信库
- **pyinstaller** (6.12.0+): 打包工具（仅打包时需要）

## 📖 使用说明

### 基本操作

1. **连接串口**
   - 从下拉列表选择串口（程序会自动记住上次使用的串口）
   - 选择波特率（默认 1,000,000）
   - 点击"打开串口"按钮
   - 串口断开后会自动尝试重连

2. **查看日志**
   - 日志实时显示在中间的文本区域
   - 默认自动滚动到最新日志
   - 向上滚动查看历史时，自动暂停跟踪
   - 滚动回底部或点击"📌跟踪最新"按钮恢复自动滚动

3. **过滤数据**
   - **实时过滤**（在数据接收时过滤）：
     - "实时显示包含"：只显示包含指定关键字的数据
     - "实时排除包含"：排除包含指定关键字的数据
     - 支持多关键字，用 `;` 分隔，如：`error;warning`
     - 按回车键应用过滤器
   - **历史筛选**（对已接收数据二次筛选）：
     - 在"筛选历史记录"输入框输入关键字
     - 按回车键筛选，只显示匹配的历史记录
     - 清空输入框并按回车可恢复显示所有记录

4. **保存数据**
   - **自动保存**：所有数据自动保存在 `serialLog/` 文件夹
   - **手动导出**：点击"💾 导出显示内容"保存当前显示的内容

5. **清空显示**
   - 点击"🗑️清空显示"清空屏幕和缓存
   - 不影响已保存的日志文件

### 配置文件说明

程序的配置保存在 `config.json` 文件中，首次运行时会自动创建。

**配置文件位置：**
- 开发环境：项目根目录下的 `config.json`
- 打包版本：与 `SerialTool.exe` 同目录下的 `config.json`

**配置项说明：**

```json
{
    "font_size": 12,                    // 界面字体大小
    "default_baud_rate": "1000000",     // 默认波特率
    "available_baud_rates": [           // 波特率下拉列表选项
        "9600", "19200", "38400", "57600", 
        "115200", "1000000", "2000000"
    ],
    "default_serial_port": "COM4",      // 默认串口（自动记忆上次使用的串口）
    "log_retention_days": 3             // 日志文件保留天数
}
```

**如何修改配置：**

1. **修改字体大小**：
   - 修改 `font_size` 的值（建议范围：10-16）
   - 重启程序生效

2. **添加自定义波特率**：
   - 在 `available_baud_rates` 数组中添加新的波特率
   - 例如：`"available_baud_rates": ["9600", "115200", "3000000"]`

3. **修改日志保留天数**：
   - 修改 `log_retention_days` 的值
   - 例如：设置为 `7` 表示保留 7 天的日志
   - 设置为 `0` 表示不自动删除日志

4. **重置配置**：
   - 删除 `config.json` 文件
   - 重启程序会自动创建默认配置

**注意事项：**
- 配置文件使用 JSON 格式，修改时请保持格式正确
- `default_serial_port` 会在每次选择串口时自动更新
- 修改配置后需要重启程序才能生效

### 日志文件

- **位置**：`serialLog/serial_tool_YYYY-MM-DD_HH-MM.log`
- **格式**：带时间戳的完整日志
- **清理**：自动删除超过指定天数的旧日志（默认 3 天）
- **查看**：程序启动时会在界面显示日志文件路径（可点击打开）

## 📦 打包为 EXE 可执行文件

如果您希望将此程序分享给没有安装Python环境的Windows用户，可以将其打包成一个独立的 `.exe` 文件。

### 使用构建脚本（推荐）

项目提供了 `build.py` 脚本来简化打包流程：

```bash
# 确保在 serial 环境中
conda activate serial

# 运行构建脚本
python build.py
```

构建脚本会自动：
- 检查 `icon_1.ico` 图标文件是否存在
- 使用 PyInstaller 打包程序
- 生成单文件可执行程序

**打包成功后**，可执行文件位于：`dist/SerialTool.exe`

### 手动打包

如果需要自定义打包参数，也可以手动执行：

```bash
pyinstaller --onefile --windowed --name SerialTool --icon=icon_1.ico main.py
```

**命令参数说明:**
- `--onefile`: 打包成单个 `.exe` 文件
- `--windowed`: GUI 模式，不显示控制台窗口
- `--name SerialTool`: 指定程序名称
- `--icon=icon_1.ico`: 指定程序图标

### 注意事项

- 确保项目根目录下有 `icon_1.ico` 图标文件
- 打包过程会创建 `build` 和 `dist` 文件夹
- 最终的可执行文件在 `dist/SerialTool.exe`
- 打包后的 exe 文件可以独立运行，无需 Python 环境
